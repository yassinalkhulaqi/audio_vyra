# Quick start

```bash
git clone <repository-url> vyra
cd vyra
cargo test --workspace
cargo run -p aurivo-desktop
```

In the app:

1. Choose input and output devices, or leave both lists empty for defaults.
2. Press **Start**.
3. Speak and watch the level meter.
4. Adjust **Gain dB** so peaks stay below −6 dB.
5. Open an effect card and move a slider to hear the change.
6. Press **Record**, speak, press **Stop**, then **Save WAV**.
7. Save a preset so you can return to this setup later.

For help with any step, see `docs/USER-GUIDE.md` and `docs/FAQ.md`.
